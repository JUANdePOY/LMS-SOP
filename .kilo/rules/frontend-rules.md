# Frontend Rules


Framework:

React + Vite


Language:

JavaScript only.

Never convert to TypeScript.


UI:

Use:

- Tailwind CSS
- Shadcn UI


Components:

Use functional components.


Naming:

Pages:

Example:

SOPListPage.jsx

Components:

Example:

SOPCard.jsx


Hooks:

Example:

useSOPs.js


Services:

Example:

sopService.js



Avoid:

- duplicated API calls
- excessive props drilling
- hardcoded values


Use:

- custom hooks
- reusable components
- constants
